gRPC Quick Start
================

Local callback adapter (test/dev)
---------------------------------

.. code-block:: php

   use Infocyph\TalkingBytes\Grpc\GrpcClient;
   use Infocyph\TalkingBytes\Grpc\Sender\GrpcRequest;
   use Infocyph\TalkingBytes\Grpc\Sender\GrpcResponse;
   use Infocyph\TalkingBytes\Grpc\GrpcStatus;

   $client = GrpcClient::using(
       static fn (GrpcRequest $request): GrpcResponse =>
           new GrpcResponse(GrpcStatus::Ok, ['echo' => $request->message]),
   );

   $result = $client->send(new GrpcRequest(
       '/orders.v1.OrderService/Create',
       ['order_id' => 1001],
   ));

   if ($result->successful) {
       $payload = $result->response->message;
   }

Node A -> Node B microservice call
----------------------------------

Use this path when Node A is a PHP service calling Node B gRPC endpoints via
generated stub clients.

.. code-block:: php

   use Infocyph\TalkingBytes\Grpc\GrpcClient;
   use Infocyph\TalkingBytes\Grpc\GrpcMetadata;
   use Infocyph\TalkingBytes\Grpc\Sender\GrpcRequest;
   use Infocyph\TalkingBytes\Grpc\Native\GeneratedStubGrpcInvoker;

   // Generated by protoc + grpc/grpc.
   $stub = new \Orders\V1\OrderServiceClient(
       'node-b.internal:50051',
       ['credentials' => \Grpc\ChannelCredentials::createSsl()],
   );

   $invoker = new GeneratedStubGrpcInvoker($stub, [
       '/orders.v1.OrderService/Create' => 'Create',
   ]);

   $client = GrpcClient::usingNative($invoker);

   $requestMessage = new \Orders\V1\CreateOrderRequest();
   $requestMessage->setOrderId('ord_1001');

   $result = $client->send(new GrpcRequest(
       '/orders.v1.OrderService/Create',
       $requestMessage,
       (new GrpcMetadata())
           ->withValue('x-request-id', 'req-123')
           ->withValue('authorization', 'Bearer token'),
       deadlineSeconds: 3.0,
   ));

   if (!$result->successful) {
       throw new \RuntimeException($result->error ?? 'gRPC call failed');
   }

   /** @var \Infocyph\TalkingBytes\Grpc\Sender\GrpcResponse $grpc */
   $grpc = $result->response;
   $responseMessage = $grpc->message;

3rd-party gRPC calls
--------------------

The same ``usingNative()`` flow works for external providers:

- map API method path with ``methodMap``
- set explicit deadline
- send auth metadata
- add ``withGrpcRetry()`` only for idempotent methods

Request model
-------------

``GrpcRequest`` validates:

- method format
- metadata keys/values
- deadline bounds

Response model
--------------

``GrpcResponse`` includes:

- ``status`` (``GrpcStatus``)
- message
- headers and trailers metadata

Failures are mapped into ``CommunicationResult`` with error metadata.
